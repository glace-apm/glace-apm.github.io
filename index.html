Features ✨

Here's a breakdown of what Glace APM has to offer.

🔑

Password Generation

Generates strong passwords with complex algorithms.

🛡️

Password Strength Checker

Estimates the strength of your password so you can create stronger ones. Uses a constantly learning AI to stay up-to-date with today's password standards.

👤

Username Generator

Lets you generate usernames for various accounts.

🔍

Common Passwords Check

Lets you check if a password is commonly used on the internet.

🔐

Master Password

Set one single password for all your passwords.

Security

How your credentials are protected.

Encryption

Your Master Password is used to generate an encryption key using PBKDF2-HMAC-SHA256 with 600,000 iterations to securely encrypt and decrypt your credentials. This means your credentials cannot be decrypted without your Master Password. This meets the OWASP 2023 security recommendations.

Customization 🎨

Make Glace APM your own.

Light & Dark Mode

Default Light and Dark modes are built into the program for comfortable viewing.

Transparency Mode Unavailable on Linux

Enable a semi-transparent window mode.

Built-in Themes

Make your APM colorful using the built-in themes.
